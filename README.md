# SDI Ventures Public Skills

Free, open skills from **Sustainable Digital Impact Ventures (SDI Ventures)**. SDI Ventures helps companies and people create websites and mobile apps, and we're sharing a few of the AI assistant skills we use so anyone can put them to work.

## What's inside

| Skill | What it does |
| --- | --- |
| [Interview prep](interview-prep/SKILL.md) | Builds a focused prep folder for a specific company and role before a recruiter screen, hiring manager call, or interview. |
| [Job application automation](job-application-automation/SKILL.md) | Finds, qualifies, fills, and logs job applications across free ATS platforms, job boards, and career sites, and skips duplicates. |
| [Resume audit](resume-audit/SKILL.md) | Reviews and scores a resume, optionally against a job description, then tells you whether to send it or tweak it first. |

## How to use them

1. Download this repo with the green **Code** button (then **Download ZIP**), or clone it:
   ```
   git clone https://github.com/sdiventures/sdi-ventures-public.git
   ```
2. Pick the skill folder you want. Each one has a single `SKILL.md` file.
3. Add that file to your AI assistant's skills or instructions (for example, a skills folder, a custom instructions field, or a project knowledge file).
4. Ask your assistant for the task in plain words, like "help me prep for my interview at Acme," and it will follow the skill.

Every `SKILL.md` ends with the SDI Ventures footer. Please keep it in place when you share or adapt a skill.
